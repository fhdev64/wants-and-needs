# Хотелки ✦

Десктоп-приложение для Windows, чтобы вести список желаемых покупок и находить лучшие цены по всему Рунету.

Загрузите фото товара или введите название. Нейросеть определит модель, соберёт описание, характеристики, плюсы и минусы, а затем найдёт предложения на маркетплейсах, в магазинах и на Авито. Все цены в рублях, отсортированы от дешёвых к дорогим.

Интерфейс сделан в духе **Apple Liquid Glass / visionOS**: матовое стекло, преломление на кромках, пружинные анимации.

## Возможности

- **Поиск по фото или названию.** Нейросеть предлагает несколько подходящих моделей, вы выбираете нужную.
- **Быстрый параллельный сбор цен.** Описание и четыре группы источников ищутся одновременно, результаты появляются по мере готовности:
  - Ozon и Wildberries
  - Яндекс Маркет, Мегамаркет, AliExpress Россия
  - Магазины: DNS, М.Видео, Эльдорадо, Ситилинк, re:Store, МТС…
  - Авито, Юла, уценка и восстановленные товары
- **Новый, б/у или уценка.** Фильтр по состоянию и отдельная минимальная цена для каждого состояния.
- **Только рубли.** Предложения с оплатой в рублях и доставкой по России.
- **Защита от мошенников.**
  - Проверенные площадки помечаются зелёным щитом.
  - Незнакомые сайты отмечаются отдельно.
  - Подозрительно низкая цена помечается и не попадает в минимальную.
  - Открываются только ссылки по https.
- **«Искать самостоятельно».** Кнопки сразу открывают поиск товара на Авито, Ozon, WB, Яндекс Маркете, Мегамаркете, DNS, М.Видео, AliExpress.
- **Мои хотелки.** Сохранённые товары с поиском, сортировкой и обновлением цен в один клик.
- **Любая нейросеть:**

  | Провайдер | Веб-поиск |
  |---|---|
  | Anthropic Claude | ✅ |
  | OpenAI | ✅ |
  | Google Gemini | ✅ |
  | OpenRouter | ✅ (`:online`) |
  | Perplexity | ✅ встроенный |
  | Codex backend (например, codexapi.work) | ✅ |
  | Любой OpenAI-совместимый API (Groq, DeepSeek, Ollama, LM Studio…) | ❌ |

  Провайдер определяется по ключу автоматически или выбирается вручную.

## Установка

Скачайте `Hotelki.exe` из [Releases](https://github.com/fhdev64/wants-and-needs/releases) и запустите. Установка не нужна: это портативная версия.

При первом запуске откроются **Настройки**. Вставьте API-ключ любой нейросети из списка выше.

> Ключ и список хотелок хранятся только локально, в `%APPDATA%\Хотелки\data.json`.

## Сборка из исходников

Нужен Node.js 20+.

```bash
npm install
npm start          # запуск в режиме разработки
npm run dist       # сборка портативного dist/Hotelki.exe
```

Если `electron-builder` падает с ошибкой создания символической ссылки (`winCodeSign`), включите в Windows «Режим разработчика» или запустите сборку от администратора.

## Устройство

```
main.js       — главный процесс Electron: окно, хранение данных, запросы к нейросетям
preload.js    — безопасный мост между интерфейсом и главным процессом
src/
  index.html  — разметка окна
  styles.css  — дизайн-система: матовое и жидкое стекло, концентрические радиусы, анимации
  glass.js    — преломление на кромках стекла (SVG-карта смещений + backdrop-filter)
  app.js      — интерфейс: список, добавление, карточка товара, настройки
```

Запросы к API нейросетей идут из главного процесса. Ключ не попадает в код страницы.

## Ограничения

- Цены собирает нейросеть с веб-поиском, поэтому они могут быть неточными или устаревшими. Перед покупкой проверяйте цену на сайте.
- Авито плохо индексируется поисковиками. Для него лучше подходит кнопка «Искать самостоятельно».
- Отсев мошеннических сайтов снижает риск, но не гарантирует безопасность. Проверяйте продавца и пользуйтесь безопасной доставкой.
