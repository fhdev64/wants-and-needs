# Хотелки ✦

Десктоп-приложение для Windows, чтобы вести список желаемых покупок и находить лучшие цены по всему Рунету.

Загрузите фото товара или введите название. Нейросеть определит модель, соберёт описание, характеристики, плюсы и минусы, а затем найдёт предложения на маркетплейсах, в магазинах и на Авито. Все цены в рублях, отсортированы от дешёвых к дорогим.

Интерфейс сделан в духе **Apple Liquid Glass / visionOS**: матовое стекло, преломление на кромках, пружинные анимации.

## Возможности

- **Поиск по фото или названию.** Нейросеть предлагает несколько подходящих моделей, вы выбираете нужную.
- **Прямой поиск по площадкам.** Авито, Wildberries, Ozon и Яндекс Маркет открываются в скрытом окне встроенного браузера, как будто вы сами зашли на сайт. Приложение читает реальные объявления и цены, а аксессуары, копии и неподходящие модели отсеивает.
- **Поиск через нейросеть** параллельно с прямым: крупные магазины (DNS, М.Видео, Эльдорадо, re:Store, МТС…), Мегамаркет, AliExpress Россия, уценка и восстановленные товары. Все результаты появляются по мере готовности.
- **Город.** Перед поиском можно указать город. Объявления Авито ищутся в нём, нейросеть учитывает самовывоз и доставку, а у объявлений показывается место продавца.
- **Проверка на площадке.** Если сайт показывает капчу или проверку, приложение предлагает открыть его окно, чтобы вы прошли её сами. Куки сохраняются, дальше поиск идёт автоматически.
- **Новый, б/у или уценка.** Фильтр по состоянию и отдельная минимальная цена для каждого состояния.
- **Только рубли.** Предложения с оплатой в рублях и доставкой по России.
- **Защита от мошенников.**
  - Проверенные площадки помечаются зелёным щитом.
  - Незнакомые сайты отмечаются отдельно.
  - Подозрительно низкая цена помечается и не попадает в минимальную.
  - Открываются только ссылки по https.
- **«Искать самостоятельно».** Кнопки сразу открывают поиск товара на Авито, Ozon, WB, Яндекс Маркете, Мегамаркете, DNS, М.Видео, AliExpress.
- **Мои хотелки.** Сохранённые товары с поиском, сортировкой и обновлением цен в один клик.
- **Любая нейросеть:**

  | Провайдер | Веб-поиск |
  |---|---|
  | Anthropic Claude | ✅ |
  | OpenAI | ✅ |
  | Google Gemini | ✅ |
  | OpenRouter | ✅ (`:online`) |
  | Perplexity | ✅ встроенный |
  | Codex backend (например, codexapi.work) | ✅ |
  | Любой OpenAI-совместимый API (Groq, DeepSeek, Ollama, LM Studio…) | ❌ |

  Провайдер определяется по ключу автоматически или выбирается вручную.

## Установка

- **Windows:** скачайте `hotelkino.exe` из [Releases](https://github.com/fhdev64/wants-and-needs/releases) и запустите. Это портативная версия, установка не нужна.
- **Android:** установите `app-release.apk`.
- **Telegram:** бот [@hotelkinobot](https://t.me/hotelkinobot).

Вход в приложения — через **VK ID, Google или Apple ID** (страница входа открывается в браузере, затем приложение открывается само). На Android «Войти с VK ID» открывает установленное приложение VK, а «Войти через Google» — системный выбор аккаунта; если это невозможно (нет приложения VK, ключи не зарегистрированы, ошибка или отмена), вход идёт через браузер. Телеграм-бота можно привязать после входа: «Профиль → Привязать Telegram». Хотелки общие для бота, компьютера и телефона и хранятся на сервере. Ключи нейросети и провайдеров входа есть только на сервере.

## Сервер

`server/` — это Node 24 (API на порту 8787, Telegram-бот, проверка цен по расписанию, Puppeteer для прямого поиска). Развёртывание на чистом Ubuntu 24.04:

```bash
scp server/deploy/setup.sh root@HOST:/root/ && ssh root@HOST bash /root/setup.sh
```

`setup.sh` ставит Caddy: API отвечает по https на 443 (адрес вида `188-120-246-113.sslip.io`, сертификат Let's Encrypt получается сам; можно задать свой домен `DOMAIN=...`). Порт 8787 остаётся запасным маршрутом.

Затем положите секреты в `/opt/hotelki/server/.env` и выполните `systemctl restart hotelki`:

| Переменная | Что это |
|---|---|
| `AI_PROVIDER`, `AI_KEY` | нейросеть |
| `PUBLIC_URL` | https-адрес сервера, например `https://188-120-246-113.sslip.io` |
| `VK_CLIENT_ID` | [id.vk.com/business](https://id.vk.com/business/go) → приложение типа «Web», доверенный Redirect URL `PUBLIC_URL/auth/cb/vk`, доступ к почте |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | Google Cloud → Credentials → OAuth client «Web application», redirect URI `PUBLIC_URL/auth/cb/google` |
| `APPLE_CLIENT_ID`, `APPLE_TEAM_ID`, `APPLE_KEY_ID`, `APPLE_PRIVATE_KEY` | developer.apple.com: Services ID с Sign in with Apple, Return URL `PUBLIC_URL/auth/cb/apple`; ключ .p8 — путь к файлу или содержимое с `
` |
| `VK_ANDROID_CLIENT_ID` | необязательно: ID Android-платформы в VK ID, если он отличается от `VK_CLIENT_ID` (см. «Вход через приложения на Android») |
| `BOT_TOKEN`, `TG_RELAY` | необязательно: Телеграм-бот для привязки |

Способ входа без ключей просто не показывается в приложениях.

### Вход через приложения на Android

Пакет приложения — `app.hotelki.hotelki`. Релизный APK пока подписан **debug-ключом** той машины, где его собирали; отпечатки берутся так:

```bash
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android
```

Для debug-ключа на машине сборки сейчас: SHA-1 `72:72:5D:3D:94:A0:64:93:6F:15:91:ED:03:60:CC:4D:76:15:C1:74`, SHA-256 `C0:6D:6A:E6:34:49:2C:82:18:43:51:17:D1:D7:75:90:F7:67:36:D2:17:FC:67:39:9F:75:B0:EB:5A:4F:A0:8F`. Если перейти на свой ключ подписи, отпечатки нужно поменять в обоих кабинетах.

- **VK ID** ([id.vk.com/business](https://id.vk.com/business/go)): в приложении добавьте платформу **Android** — пакет `app.hotelki.hotelki` и SHA-1 отпечаток (если форма не принимает двоеточия, вводите без них). Redirect URL для Android — `vk<ID приложения>://vk.ru/blank.html`. ID вписывается в сборку: `vkClientId=<ID>` в `mobile/android/local.properties` (или `flutter build apk --android-project-arg=vkClientId=<ID>`). Если у Android-платформы свой ID, укажите его и на сервере в `VK_ANDROID_CLIENT_ID`. Код из приложения VK обменивает сервер (PKCE, `POST /api/auth/vk/code`), секретов в APK нет. Сборка без `vkClientId` или с ID, не совпадающим с сервером, входит через браузер.
- **Google** (Google Cloud → Credentials): создайте ещё один OAuth client типа **Android** — пакет `app.hotelki.hotelki` и SHA-1. Его ID никуда вписывать не нужно: приложение просит токен для веб-клиента (`GOOGLE_CLIENT_ID`, сервер отдаёт его в `/api/health`), а сервер проверяет `aud` через `oauth2.googleapis.com/tokeninfo` (`POST /api/auth/google/token`). Android-клиент и веб-клиент должны быть в одном проекте Google Cloud.

Если вход через приложение отменён или сломался, следующее нажатие той же кнопки сразу открывает браузер.

С российского хостинга `api.telegram.org`, nodejs.org и npmjs недоступны:
- Node.js и npm-пакеты `setup.sh` берёт с зеркал;
- запросы бота идут через прокси на Google Apps Script. Код прокси лежит в `server/deploy/tg-relay.gs`. Опубликуйте его как веб-приложение с доступом «Все» и укажите URL в `.env` как `TG_RELAY=`. Этот же прокси — запасной маршрут к API для клиентов за VPN.

Сеть в приложениях: при запуске они параллельно опрашивают https-домен и IP:8787 и работают через тот адрес, что ответил первым; если оба недоступны (VPN, блокировки) — через Apps Script. Ответы API сжимаются gzip, соединения держатся открытыми между запросами, оборвавшиеся GET-запросы повторяются.

## Сборка из исходников

```bash
npm install && npm run dist                     # dist/hotelkino.exe (адреса сервера: package.json → hotelki.servers)
cd mobile && flutter build apk --release        # адреса по умолчанию в lib/api.dart, свои: --dart-define=SERVER=https://...,http://...; VK ID SDK — vkClientId в android/local.properties
cd server && npm install && node src/index.js   # локальный сервер
```

## Устройство

```
main.js, preload.js   — Electron: окно, мост к серверу (IPC srv), фирменные уведомления
src/                  — интерфейс ПК (app.js, styles.css, notify.*)
mobile/lib/           — Flutter-приложение (main, product, ui, api, notify)
server/src/           — api, oauth (VK ID, Google, Apple), bot, search, shops (Puppeteer), ai, watch (история цен, уведомления), db (SQLite)
server/deploy/        — setup.sh для VPS, tg-relay.gs
```

## Ограничения

- Цены собирает нейросеть с веб-поиском, поэтому они могут быть неточными или устаревшими. Перед покупкой проверяйте цену на сайте.
- Авито и Ozon блокируют иностранные IP, поэтому сервер должен стоять в России.
- Отсев мошеннических сайтов снижает риск, но не гарантирует безопасность. Проверяйте продавца и пользуйтесь безопасной доставкой.
